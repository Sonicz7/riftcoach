# RiftCoach

Coach League of Legends en français : picks, bans, runes, build adapté, conseils en direct et débrief après chaque partie.
Utilise uniquement les API officielles de Riot (aucune triche : pas de lecture mémoire, pas de suivi des ennemis invisibles).

## Installer

1. Télécharge `RiftCoach-Setup-x.y.z.exe` dans [Releases](https://github.com/Sonicz7/riftcoach/releases/latest).
2. Lance-le. Si Windows affiche « Windows a protégé votre ordinateur » : **Informations complémentaires** → **Exécuter quand même**.
3. Lance League of Legends puis RiftCoach : ton compte et ton rang sont détectés tout seuls.

Les mises à jour s'installent ensuite automatiquement (jamais pendant une partie).
